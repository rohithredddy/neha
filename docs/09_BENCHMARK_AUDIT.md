# N2 Benchmark Audit — summary (2026-10-24)

The full write-up is `docs/paper/audit_paper_draft.md`. All numbers are in `results/tables/tables.md`.
Reproduce with `make audit` (scripts/run_audit_all.sh, ~2–3 h CPU, no GPU).
Results were generated at commit `91d0854`. A second full run reproduced all 5,305 numbers exactly.

## Headline findings
1. **The binary task is a ligand-size test.** Docking score vs heavy atoms: ρ = −0.89.
   Heavy-atom count alone scores 98.7 AUROC on ID (FusionDTI 98.3). Ligand-only GBM: 99.8–99.9.
   Adding protein features to a learned model adds ≤ 3.1 AUROC on every split.
2. **Localization works without the ligand.**
   - ID: homology transfer 57.5 / 77.1 BRHR@1/@5; ESM-2 8M probe 23.4 / 57.8 (fold 0);
     FusionDTI 21.6 / 35.6.
   - p_ood_33: 70.4 (homology) and 56.5 (probe) vs 30.1 BRHR@5 (FusionDTI).
   - The ligand-agnostic oracle gives 60–69 BRHR@1 on every split.
3. **The OOD splits leak.** p_ood_33 has ≥ 60.7% of test pairs above its 33% cap by global NW
   identity. For p_ood_25–31 the answer depends on the identity formula.
4. **MMseqs2 30% clustering (`--cov-mode 0`) leaks**: 34% of test pairs keep a near-identical train
   neighbour. The leak-defined split `id_lc30` (either-direction coverage, connected components,
   4 folds) removes it. Homology transfer still gets 21.7 / 43.5 there, from remote homologs.
5. **Size-matching removes size, not the shortcut**: ligand-only GBM 91.8–95.0 on size-matched ID.
