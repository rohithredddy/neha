# What Does InteractBind Measure? Ligand-Size Shortcuts, Sequence Leakage, and Ligand-Blind Baselines in Drug–Target Interaction Benchmarks

*Draft v0.2 (2026-10-24). Target: IEEE BIBM 2027 (short/regular) or a BIBM workshop. Every number
comes from `results/tables/tables.md`, generated by `make audit` from commit `f729d49`. A second
full run reproduced all 5,305 reported numbers exactly.*

---

## Abstract

InteractBind is a new ~100k-pair benchmark. It asks drug–target interaction (DTI) models to say
both *whether* a ligand binds and *where*, as residue-level binding sites. Published models reach
98% AUROC but find the top binding residue only ~22% of the time, which has been read as "models
learn binding likelihood, not binding sites". We audit what the benchmark rewards, using only
CPU-scale baselines. (i) The binary labels are thresholds on docking scores. Docking scores track
ligand size (Spearman ρ = −0.89). A ligand's heavy-atom count alone, with no protein and no
training, scores 98.7 AUROC on the in-distribution task, against 98.3 for the best published model.
A ligand-only gradient-boosting model scores 99.8–99.9. Given both drug and protein, a learned model
gains at most 3.1 AUROC points over the ligand-only model, on every split. (ii) Residue localization is largely solvable without
the ligand. Copying binding sites from sequence homologs in the training set, and a linear probe on
a small protein language model that never sees the ligand, both match or exceed published
interaction models. A ligand-agnostic ceiling built from other ligands' sites reaches 60–69%
BRHR@1. (iii) The protein-similarity OOD splits leak. On the 33% split, at least 61% of test pairs
have a training protein above the cap by global Needleman–Wunsch identity, under both identity
definitions we tested. For the 25–31% splits the answer depends on the unstated identity formula. Standard 30% MMseqs2 clustering also leaves leaks, because it
requires coverage in both directions. We release a leak-defined split, which removes the homolog
leak but not the ligand shortcut. We recommend that ligand-only, protein-only and homology baselines
be reported alongside any DTI result on this benchmark.

## 1. Introduction

- DTI interpretability claims rest on attention or interaction maps. InteractBind [1] is the first
  large public benchmark that scores those maps against residue-level ground truth, using BRHR@K.
- Its headline result is a gap: FusionDTI scores 98.3 AUROC but 21.6 BRHR@1. This motivated
  map-supervised models such as ExplainBind [2], which reports 55.6 BRHR@1.
- Before building on a benchmark, one should ask what its numbers reward. Benchmark-artifact
  studies in DTI and docking [3–6] show that high scores can come from dataset structure: decoy
  size bias, train/test overlap and hidden ligand bias.
- **Contributions.**
  1. A binary-task shortcut analysis. The label is a docking-score threshold, and ligand size
     predicts it (Spearman ρ = −0.89 between heavy atoms and docking score).
  2. Ligand-blind localization baselines: training-free homology transfer, and an ESM-2 linear
     probe trained on CPU in minutes. Both match or beat published interaction models.
  3. A split audit under local (MMseqs2) and global (Needleman–Wunsch) identity, plus an analysis
     of why standard clustering still leaks.
  4. A leak-defined protein split and a size-matched evaluation subset, released with all code.
     Everything runs on a laptop CPU in about 3 hours (`make audit`).

## 2. Background: InteractBind

- About 99k protein–ligand pairs from PDB complexes. Residue-level binding sites are given for six
  non-covalent interaction types plus "overall". In the public release they are per-residue binary
  strings aligned to the FASTA [1, HF data card].
- Labels come from AutoDock Vina docking: positive if affinity ≤ −7 kcal/mol, negative if > −5, and
  the band between is discarded [1, App. C.1].
- Splits:
  - ID: 5-fold CV over 84,809 pairs; the fold assignment is not public.
  - Four protein-OOD splits capped at 25/28/31/33% train–test similarity by global
    Needleman–Wunsch alignment, 8:1:1.
- Metric: BRHR@K = fraction of pairs whose top-K residues (by max over ligand units of the
  interaction map) contain at least one annotated binding residue.

## 3. Methods

All code is in this repository. Decisions are logged with reasons in `docs/DECISIONS.md`.

### 3.1 Splits
- **ID, FASTA-grouped (5 folds).** Our replacement for the unpublished ID folds. Pairs are grouped
  by exact protein sequence, because 6,308 sequence–ligand pairs occur more than once.
- **ID, MMseqs2 30% clusters (5 folds)**, in set-cover and connected-component modes:
  `--min-seq-id 0.3 -c 0.8 --cov-mode 0`.
- **ID, leak-defined components (4 folds, proposed).**
  - Run an all-vs-all MMseqs2 search.
  - Add an edge when identity ≥ 30% and the alignment covers ≥ 80% of *either* sequence.
  - Take connected components (union-find), then assign whole components to folds.
  - The largest component holds 23.8% of pairs, which rules out 5 balanced folds.
- **Public protein-OOD splits**, used unmodified.

### 3.2 Binary-task baselines
- Key priors: the smoothed train positive rate of the test pair's protein (exact FASTA or UniProt)
  or ligand (SMILES).
- Single RDKit descriptors used directly as scores, with no training (e.g. heavy-atom count).
- HistGradientBoosting with fixed hyperparameters, on three input sets:
  - ligand features: Morgan fingerprint (radius 2, 1024 bits), or all RDKit 2D descriptors;
  - protein features: amino-acid and dipeptide composition;
  - both concatenated.
- **Size-matched subset:** within each exact heavy-atom count, an equal number of positives and
  negatives (seeded). Heavy-atom AUROC is 0.5 on it by construction.

### 3.3 Localization baselines
None of these uses the ligand unless stated. All are evaluated on annotated test positives.
- **Random ranking.** Analytic expectation 1 − C(L−n⁺, K)/C(L, K).
- **Exact lookup.** Binding-site frequency over train pairs with the identical FASTA.
- **Homology transfer (kNN).** Take the top-5 MMseqs2 hits (`-s 7.5`) among annotated train
  sequences. Map each hit's binding frequency through the alignment and weight it by identity. A
  ligand-weighted variant re-weights each train pair by Morgan Tanimoto similarity to the test
  ligand.
- **ESM-2 probe.** A logistic regression on frozen `esm2_t6_8M` residue embeddings, trained on 2,000
  train proteins per split. Residue label: binding in at least one train pair.
- **Ligand-agnostic oracle (ceiling, uses test labels).** Rank each protein's residues by binding
  frequency over the *other* test ligands of the same protein (leave-one-out). This is an upper
  bound for any method that gives all ligands of a protein the same ranking.
- BRHR is computed by one shared implementation that matches the benchmark's definition and is
  unit-tested on hand-built maps. Alignment-to-residue index mapping is unit-tested by hand, and
  every alignment is checked against the real sequences at run time.

### 3.4 Split audit
- For each test pair: the nearest train protein by MMseqs2 local identity, overall and restricted
  to alignments covering ≥ 80% of the test sequence.
- Global Needleman–Wunsch identity (BLOSUM62, gap −10/−0.5, free end gaps, EMBOSS-needle style),
  computed against the top-10 MMseqs2 candidates. This gives a lower bound on the true maximum.
  Two identity denominators are reported: alignment length and shorter sequence.
- A background distribution from 1,000 random test–train pairs.

### 3.5 Reproducibility
- Seed 0 throughout. Seeds only affect tie-breaking noise, subset sampling and GBM randomness.
- Every number comes from a JSON in `results/`, which records the git commit and full config.
- Total compute is about 3 h on a 10-thread laptop CPU, with no GPU.

## 4. Related work

- **DTI benchmark artifacts.** Pair-random splits inflate scores. Protein, ligand and pair cold
  splits are needed [3]. Shortcut audits of sequence-based DTI models [4]. Leak-aware evaluation
  of pocket and protein priors in affinity prediction [5].
- **Docking-score size bias.** Docking scores correlate with ligand size. Decoy sets are
  size-matched for this reason, and size-normalised scores have been proposed [6, 7].
- **Interaction-map supervision.** MONN and ArkDTA used NCI labels on PDBbind. ExplainBind [2]
  supervises per-type attention on InteractBind. Our results suggest such gains should be
  reported against ligand-blind and homology baselines.

## 5. Results

### 5.1 The binary label is a ligand-size threshold
- Docking score vs. ligand heavy-atom count over all 84,809 ID pairs: Spearman ρ = −0.89. The label
  is a threshold on that score (score separates labels with AUROC 1.0).
- **Ligand alone solves ID** (Table T_binary_auroc):
  - heavy-atom count, no training: 98.7 ± 0.1 AUROC;
  - ligand-only GBM: 99.9;
  - published FusionDTI: 98.3, ExplainBind: 99.3.
  - This holds on every ID split variant, including the leak-free one (98.7 / 99.8).
- **Protein identity carries little label signal.**
  - Exact-protein prior: 50.0 everywhere, because ID folds are grouped by sequence.
  - UniProt prior: 51.8–57.5.
  - On OOD, protein priors score at chance.
- **On OOD the ligand still dominates.** Ligand-only GBM: 85.7 / 87.9 / 89.8 / 88.5 AUROC on the
  25 / 28 / 31 / 33% splits. That beats FusionDTI on p_ood_25 (81.8) and trails it on p_ood_33
  (91.8).
- **Learned pair models collapse to the ligand** (T_pair_models_auroc). With identical GBMs:
  - adding protein features to ligand features changes AUROC by +0.0 to +3.1 on every split;
  - protein-only scores 81.9 on FASTA-grouped ID, but only 64.1 on leak-free ID and 49.6–53.9 on
    OOD. Its ID signal is homology leakage.
- **Size-matching is necessary but not sufficient.** On the size-matched subsets (heavy-atom AUROC
  exactly 0.5), ligand-only GBMs still score 91.8–95.0 on ID and 61.6–75.2 on OOD. Other ligand
  chemistry still predicts the docking label.

### 5.2 Localization without the ligand
(T_localization_brhr1/5, T_esm_probe_brhr.)
- **Homology transfer, no training,** on FASTA-grouped ID:
  - kNN: 57.5 BRHR@1 and 77.1 @5;
  - with ligand weighting: 61.6 / 79.4;
  - published FusionDTI: 21.6 / 35.6; ExplainBind (reported): 55.6 / 74.6.
- **On the public OOD splits** (directly comparable), homology kNN BRHR@5 is 56–70 on p_ood_28–33,
  against FusionDTI's 30.1 on p_ood_33. FusionDTI wins on p_ood_25 (28.4 vs. 14.3). That split
  pairs short train proteins with long test proteins.
- **A learned ligand-blind model.** The ESM-2 (8M) linear probe, trained in about 2 min on CPU,
  reaches:
  - 23.4 / 57.8 on ID fold 0 (FusionDTI: 21.6 / 35.6);
  - 56.5 @5 on p_ood_33 (FusionDTI: 30.1);
  - 26.6 @5 on p_ood_25 (FusionDTI: 28.4).
  - On p_ood_25 it beats homology transfer, so it is not just lookup.
- **Ligand information adds little.** Ligand-weighted kNN improves BRHR@1 by at most 4.1 points.
- **The ligand-agnostic oracle**, which uses the other ligands' sites on the same protein, reaches
  60–69 BRHR@1 and 73–92 @5 on every split. A model that never reads the ligand could, in
  principle, exceed every published number.

### 5.3 The OOD splits leak
(T_split_audit, T_global_identity.)
- **Local identity (MMseqs2):** 71–82% of OOD test pairs have a train protein above the nominal
  cap. With the alignment required to cover ≥ 80% of the test protein, this is 0.0 / 25.0 / 32.4 /
  58.2% for the 25 / 28 / 31 / 33% splits.
- **Global Needleman–Wunsch identity** (the benchmark's own type of measure), as a lower bound from
  top-10 candidates:
  - **p_ood_33:** 60.7% of test pairs exceed 33% (identities ÷ alignment length), or 67.4%
    (÷ shorter length). Random test–train pairs exceed it only 0.5% of the time (median 8.5%).
  - **p_ood_25 to 31:** the answer depends on the identity definition, which the benchmark does
    not state. Under the alignment-length definition, 3.8 / 18.0 / 29.0% of pairs exceed the cap.
    Under the shorter-length definition, 56.6 / 59.5 / 46.2%.
- **Localization tracks identity** (F2). On p_ood_33, homology-kNN BRHR@1 rises from 20.2 for
  pairs with < 30% nearest identity to 63.9–67.8 for pairs above 50%. Random ranking stays at ~4.3.

### 5.4 Standard clustering still leaks; a leak-defined split does not
- **MMseqs2 30% clustering,** in both set-cover and connected-component modes, leaves 34.0% of
  test pairs with a ≥ 90%-identity, ≥ 80%-coverage train neighbour. Homology kNN still scores
  31–33 BRHR@1 there.
- **The cause is `--cov-mode 0`,** which requires coverage of *both* sequences, so fragments and
  domains never join their full-length parents.
- **Our leak-defined components** (edge if identity ≥ 30% and coverage of *either* sequence ≥ 80%)
  remove the leak: 0.0% of test pairs have such a neighbour, and the median nearest identity is
  30.9%. On this split:
  - homology kNN falls to 21.7 ± 5.2 BRHR@1 and 43.5 ± 7.8 @5. That is still 5× random, and equal
    to FusionDTI's published ID numbers;
  - the ESM probe gives 13.1 / 40.6 (fold 0);
  - the ligand shortcut is unchanged (heavy atoms 98.7, ligand-only GBM 99.8).
- **The residual signal is real.** Pairs whose top-5 homologs are *all* below 30% identity still
  reach 41.4% BRHR@1 (48.8% when the alignment covers ≥ 80%). Pairs with no homolog score at random
  (2.1%), and an amino-acid-type prior scores ~7%. Pocket position is conserved at the family
  level, below the 30%-identity line that splits usually rely on.
- **Grouping cost.** One leak-defined component holds 23.8% of ID pairs, so at most 4 balanced folds
  exist. About a quarter of InteractBind-ID is one connected protein family.

## 6. Discussion and recommendations

1. **Report shortcut baselines with every InteractBind number:** a ligand-only model, a
   protein-only model, homology transfer and the ligand-agnostic oracle. All run on a CPU in
   minutes (`make audit`).
2. **Evaluate localization on leak-defined protein splits**, built from an either-direction
   coverage graph, not `--cov-mode 0` clustering. Evaluate the binary task on size-matched subsets,
   and expect residual ligand-chemistry signal even there.
3. **BRHR measures pocket recall more than interaction.** The ligand-agnostic oracle exceeds every
   published model. Claims that a model "learns interactions" need a ligand-sensitivity measure,
   e.g. how the residue ranking changes across ligands of the same protein, compared with how the
   ground truth changes.
4. **Docking-derived labels encode ligand size.** Binary DTI labels from docking thresholds should
   be size-corrected, e.g. ligand efficiency, or paired with size-matched decoys, as is standard
   for docking benchmarks.

**Limitations.**
- Published models are not retrained, for lack of compute. A DrugBAN epoch takes ~102 min on our
  CPU. We therefore show that the shortcuts exist and are learnable, using GBMs and a linear probe.
  We do not show which shortcuts each published model uses.
- Our ID folds differ from the unpublished originals, so ID comparisons with published numbers are
  indicative. The OOD comparisons are direct.
- The ESM probe uses ESM-2 8M on fold 0 only.
- Global identity is a lower bound over MMseqs2 candidates, and the benchmark's identity formula
  is unknown.
- Seed 0 throughout. A full re-run reproduced every number exactly; other seeds only perturb
  tie-breaking and subset sampling.
